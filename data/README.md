# 시연 입력 데이터

영상 파일은 Git LFS로 관리합니다.

| 폴더 | 파일 | 사용처 |
| --- | --- | --- |
| `videos/weather/` | `2.avi`, `3.avi`, `6.avi`, `10.avi` | CCTV 대시보드·모델 비교 |
| `videos/crash/` | `1.avi`, `2.avi`, `3.avi` | USB 시연 사고 모니터·사고 실험 |

카메라 앱과 사고 실험이 같은 사고 영상을 공유합니다. 기존 두 사본은 SHA-256으로 동일함을 확인한 뒤 통합했습니다.

학습 데이터는 별도로 `data/datasets/` 또는 각 학습 도구에 지정한 경로에 준비합니다. 신규 녹화와 데이터셋은 Git에서 제외합니다.
